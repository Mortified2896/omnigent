# Lean production agent

Production uses the standalone `opencode/` bundle on upstream's
`opencode-native` harness. The server default is `opencode-native-ui`, the
canonical built-in OpenCode agent, while the bundle is available for an
explicit operator prompt and environment policy.

Verity, delegated worker bundles, mandatory review, approval, and evaluator
workflows are intentionally not part of this deployment. Upstream Pi support
remains available but is not registered or tested as a production gate.
