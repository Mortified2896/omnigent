# Contributing to Omnigent

Start with [AGENTS.md](AGENTS.md), the repository workflow for
`Mortified2896/omnigent`. Ordinary fork development is not an upstream
contribution. Follow the task's delivery instructions; this guide adds no
mandatory issue, PR, reviewer, demo, or full-suite validation requirement.

Use focused tests appropriate to the behavior and risk. Keep existing hooks,
secrets protections, branch safety, and explicit merge/deployment authorization.
Report enforced CI or repository-policy conflicts instead of bypassing them.

## Optional upstream reference

The inherited contributor guide is preserved unchanged in
[CONTRIBUTING.upstream.md](CONTRIBUTING.upstream.md). It is reference material,
not routine agent startup context. Read only a relevant setup/testing section
when needed; upstream issue triage, DCO, demo, reviewer, and delivery rules do
not define this fork's default workflow. This does not change the license or
turn off existing GitHub checks.

Only prepare a contribution to `omnigent-ai/omnigent` when explicitly requested,
and verify that repository's current requirements before submitting.
