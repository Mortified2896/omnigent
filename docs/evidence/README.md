# Historical deployment evidence

Evidence records observations for a specific revision and operation. It does not
select the current development host or establish present runtime acceptance.
Current deployment locators are owned by the
[HomeLab environment registry](https://github.com/Mortified2896/HomeLab/blob/main/docs/environments/current.json).

The [initial peer rollout](peer-rollout-20260916.md) and
[response-feedback forward port](response-feedback-forward-port.md) were separated
from durable application procedures without changing their observed contents.
Other dated diagnostics, migration assessments and explicitly historical legacy
deployment contracts remain at their original paths. Old hostnames, ports and
state labels remain historically accurate and are not current operating rules.
